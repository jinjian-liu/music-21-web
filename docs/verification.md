API 集成使用 PGlite 执行 PostgreSQL SQL，S3 使用内存对象测试替身；不是纯路由 mock，但不等同于真实 PostgreSQL 16 网络服务、多数据库连接争抢或云存储网络测试。

浏览器测试将 API 不可用作为本地优先场景；云端成功路径由 API 集成覆盖。没有声称完成真实浏览器 → 网络 API → MinIO 的全链路部署验收。
