# 界面截图

这些截图来自弦知实际运行的前端界面，更新于 2026-10-09。截图使用独立的 Chromium 浏览器上下文，不读取使用者日常浏览器的曲库、账号或练习记录。

演示曲目由项目内置《小星星》生成：主旋律、慢速和分轨三个版本均经页面正常导入。练习记录来自脚本在逐音模式中的实际按键与结束操作；不足一分钟的记录在概览中显示为 0 分钟。截图没有改写展示数字或拼接虚构界面。

截图时让 API 返回服务不可用，仅展示本机功能，不模拟已登录或云端服务正常。桌面使用 1440 × 1080 视口，手机使用 390 × 844 视口；除桌面概览外，图片包含完整页面。截图是布局展示，不代表已经完成实物手机或麦克风验收。

## 更新图片

在项目根目录安装依赖并启动前端：

```sh
npm ci
npx playwright install chromium
npm run dev -- --host 127.0.0.1
```

另开一个终端运行：

```sh
npx tsx scripts/capture-readme.ts
```

脚本默认访问 http://127.0.0.1:5173；其他地址可通过 SCREENSHOT_BASE_URL 环境变量指定。六张 PNG 会写入当前目录，更新后请逐张检查文字、画面完整性和 README 中的引用，再随文档一起提交。

- overview.png：桌面概览。
- step-practice.png：逐音跟练工作台。
- library.png：本机曲库。
- metronome.png：节拍器。
- mobile-overview.png：手机概览。
- mobile-practice.png：收起键盘后的手机工作台。
